\# ☢️ CSOPESY Vault-Tec OS GUI



A desktop-style operating system mock-up built using \*\*Dear ImGui, GLFW, OpenGL, and C++\*\* for CSOPESY Semi-Major Output 2.



> An unofficial Vault-Tec-inspired graphical operating system interface created for academic purposes.



\---



\## 🖥️ Preview



!\[Vault-Tec OS Preview](docs/assets/vaulttec-preview.png)



\---



\## ✨ Features



\- Retro CRT-style boot sequence

\- Animated system diagnostics

\- Vault-Tec OS loading screen

\- Animated Vault Boy loading graphic

\- Desktop-style graphical environment

\- Real-time system clock

\- Power / shutdown control

\- Application taskbar

\- Task Manager with process information

\- Custom retro terminal font

\- Responsive UI scaling



\---



\## 🛠️ Built With



\- C++

\- Dear ImGui

\- GLFW

\- OpenGL 3

\- stb\_image

\## 📂 Main Project



The primary project is located at:



`examples/example\_glfw\_opengl3/`



Main source file:



`examples/example\_glfw\_opengl3/main.cpp`



\---



\## 🚀 Running the Project



Open the ImGui Visual Studio solution and build:



`example\_glfw\_opengl3`



Make sure the project assets remain in their original folders so the custom fonts and animation frames can be loaded correctly.
