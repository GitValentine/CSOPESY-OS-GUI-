# CSOPESY OS GUI

A simple desktop-style OS mock-up created for CSOPESY using Dear ImGui, GLFW, OpenGL, and C++.

## Features

- Boot screen
- Loading screen
- Desktop wallpaper
- Real-time clock
- Taskbar
- Start menu
- File Explorer
- Task Manager
- Power / shutdown button

## How to Run

1. Open `CSOPESY-OS-GUI.slnx` in Visual Studio.
2. Build the project.
3. Run using `Ctrl + F5`.

## Main File

`examples/example_glfw_opengl3/main.cpp`

## Technologies Used

- C++
- Dear ImGui
- GLFW
- OpenGL
- stb_image
